# 검증 범위

## 게임 데이터

- 스토리 3,289개, 시스템 554개, 챕터 선택 제목 143개와 영상 자막 318개의 표시 폭·줄 수·지원 글리프를 검사했습니다.
- 한글 이미지 617개와 유지한 HUD 21개, 합계 638개를 최종 ISO의 실제 팔레트 이미지와 대조했습니다. 별도 메뉴·배경·프레임 219개는 원본을 보존합니다.
- 원본 글리프 1,608개와 한글 994개를 검사하고, 폰트 파일의 섹터 읽기 크기를 맞췄습니다.
- 영상 51개의 해상도·프레임 수·종료 코드와 원본 ADX 음성의 동일성을 확인했습니다. 나머지 영상 27개는 원본과 동일합니다.
- 실행 파일 헤더·적재 구역·BSS 크기와 자료 포인터, 아카이브 정렬을 검사했습니다.

## 저장 프리징 수정

리키이시전 뒤의 같은 진행 데이터에서 일본판과 기존 한글판을 비교했습니다. 한글 저장 제목 한 줄이 원래 20칸 제한을 넘던 문제를 분리해 확인했습니다. 저장 미리보기 5개를 짧게 다듬고 전체 157개의 칸 수와 실제 출력 폭을 검사했습니다. 전체 본문과 챕터 선택 제목은 축약하지 않았습니다.

PC 복사 카드에 새 저장·덮어쓰기를 한 다음, 에뮬레이터를 완전히 닫고 새로 부팅해 불러오기와 제3장 대사 진행을 확인했습니다. 이후의 UI 수정은 동일한 저장 처리 코드와 스토리 자료를 유지합니다. 원본 세이브 형식과 저장 I/O는 바꾸지 않았습니다.

이는 전편 플레이 확인과 구분합니다. 내부 정지의 모든 후속 동작을 증명한 것은 아니며, 긴 제목에 의한 회귀와 수정 효과를 같은 진행 경로에서 확인한 것입니다.

## 최근 UI 수정

경기 규칙·재대결/종료·설정의 원본 표시 사각형을 실행 파일에서 대조했습니다. 16개 문구의 최종 팔레트 픽셀이 자기 표시 영역의 위아래·좌우에 닿지 않는지 검사했습니다. 원래 숫자 영역과 직접 맞닿은 설정 첫 행은 숫자 픽셀을 지우지 않습니다.

‘싸움’과 타이틀전 문구 3개의 ㅇ 안쪽 흰 테두리를 보완했습니다. 종소리 글씨 2종은 같은 캔버스·4비트 팔레트로 바꿨으며, 애니메이션 코드·음성은 유지합니다.

최신 수정은 메뉴와 경기 표시 아카이브 두 개에 한정됩니다. 직전 검증본과 비교해 실행 파일·스토리·게임 폰트·모든 영상과 다른 파일은 바이트 단위로 동일합니다.

## 실행 화면과 이미지 출처

타이틀과 메인 화면은 공개 패치의 대상 ISO를 새로 부팅해 촬영했습니다. 경기 규칙은 같은 최신 수정본의 PCSX2 실행 화면입니다. 스토리 대사·장 시작·저장 목록·종이 메뉴는 현재도 같은 코드·자산을 유지한 검수 실행 화면입니다.

오프닝 이미지는 최종 인코딩 영상의 한 프레임입니다. UI 수정 모음은 최종 게임 팔레트의 이미지이며 실제 플레이 스크린샷과 구분했습니다. 재대결 대화상자와 종소리 순간을 최신 실행에서 촬영한 자료는 아닙니다.

스크린샷 촬영과 최근 메뉴 검사는 강제 저장 상태나 메모리 수정을 사용하지 않았습니다. 저장 동작을 조사하는 앞선 과정에서는 같은 빌드의 메뉴 상태를 다시 불러온 뒤, 실제 저장 결과는 완전 종료·새 부팅으로 검증했습니다.
