# v1.1 검증 범위

v1.1은 사용자가 지정한 비공식 한글화 정식 배포 번호입니다. 배포 게임 내용은 내부 검수본 v0.9.15와 바이트 단위로 같으며 결과 ISO SHA-256으로 구분합니다. 정식 릴리스 표시는 아래 미검증 항목의 완료를 뜻하지 않습니다.

## 데이터·원본 보존 검사

- 스토리 3,289개, 시스템 554개, 장 시작 14개와 챕터 카드 143개, 중앙 제목·시합 조건 100개, 저장 제목 157개의 제어 코드·글리프·출력 범위를 검사했습니다.
- 한글화 이미지 617개와 유지한 HUD를 포함한 638개 검수 자료를 최종 팔레트와 대조했습니다. 별도 메뉴·배경·프레임 219개를 유지합니다.
- 원본 글리프 1,608개와 한글 994개, FONT.BIN의 섹터 읽기 정렬을 확인했습니다.
- 자막 영상 52개의 전체 디코딩·프레임 수·해상도·화면 비율·종료 코드를 검사하고 원본 ADX 음성의 동일성을 확인했습니다. 영상 26개는 원본과 동일합니다.
- ELF 헤더·적재 구역·BSS 크기, 포인터, 아카이브 정렬과 ISO9660 범위를 검사했습니다. 이 검사가 실기 동작을 증명하는 것은 아닙니다.
- 마지막 장 이동 추가는 내부 v0.9.14 대비 실행 파일과 SYSFONT.RAW 두 파일만 바꿉니다. 스토리·본편 폰트·기존 UI/HUD·78개 영상은 내부 v0.9.14와 동일합니다.

## 새 SELECT 장 이동

- 기존 게임의 비동기 장 초기화/정리 경로로 14개 장의 시작을 로딩했습니다. 19회 반복 이동에서 같은 장으로 돌아올 때 메모리 여유가 계속 줄지 않는 것을 확인했습니다.
- 이때 실행한 로딩 작업 188바이트는 최종 배포의 작업 코드와 동일합니다. 이후 강화한 호출 조건은 최종 명령을 직접 실행하는 39개 사례로 검사했습니다. 레지스터 보존과 분기 지연 슬롯을 포함합니다.
- 최종 ISO를 새로 부팅해 로딩 코드와 글꼴 자료를 읽었고, SELECT 열기·× 취소·SELECT 취소·제14장 이동을 확인했습니다.
- PCSX2 PINE 디버거로 버튼을 주입하고 시작 스토리 진입을 준비했습니다. 배포용 장 선택 본체를 바꾼 검사가 아니지만, 전체를 일반 플레이 경로로 완주한 검사는 아닙니다.
- 전투 화면과 실제 저장 슬롯 메뉴에서 호출 차단을 확인했습니다. 기존 일시정지·저장 하위 메뉴 전체를 제외하고 일반 대사 상태에서만 열리도록 했습니다.
- 이동 후 메모리카드에 새 저장을 끝내고 다시 불러오는 전체 검사는 완료하지 않았습니다. 저장 I/O·세이브 파일 형식은 유지합니다.

## 기존 저장 프리징 수정

내부 v0.9.8에서 리키이시전 뒤 같은 진행 데이터로 일본판과 한글판을 비교했습니다. 긴 한글 저장 제목이 원래 제한을 넘는 원인을 분리해 수정하고 PC 복사 카드에서 새 저장·덮어쓰기·완전 종료 후 재부팅·불러오기·제3장 대사 진행을 확인했습니다. 그 수정은 이후 버전에도 유지됩니다.

이는 새 SELECT 장 이동 후의 저장 완료 검사와 구분합니다. 과거 정상 저장 검사를 새 기능 뒤의 정상 저장 검사로 바꾸어 주장하지 않습니다.

## 전체 개방 세이브

- 기존 챕터 선택 143개 개방 비트를 변경하고 옵션·캐릭터 해금 정보·스토리 슬롯은 보존했습니다.
- 원본 개방 판정 코드 286회 실행: 변경 전 17개, 변경 후 143개.
- 시스템 체크값, 전체 16,384페이지 ECC, PSU·카드 가져오기/내보내기 왕복을 검사했습니다.
- 별도 카드의 PC 부팅 읽기를 확인했습니다. 실제 챕터 메뉴 전체 탐색·모든 기기에서의 적용은 미검증입니다.
- 사용자의 원래 메모리카드는 변경하지 않았습니다. 배포 카드는 이 게임 데이터만 담은 별도 카드입니다.

## 패처

Windows EXE는 원본 ISO를 읽기 전용으로 열고 SHA-256·크기를 확인합니다. 차분과 결과 ISO도 검증하며, 원본 또는 기존 출력 파일을 덮어쓰지 않습니다. 기존 파일 보존·잘못된 원본/패치·다른 버전 패키지 거부의 5개 검사를 통과했습니다. 실제 전체 ISO 적용 결과는 [EXE 적용 검사](PATCHER-VERIFICATION.json)에 있습니다.
